# Գրիշա և Մարինե — Wedding Invitation

Mobile-first Armenian wedding invitation for 20 November 2026.

## GitHub Pages
Upload all files and folders to the root of the repository. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Before sharing with guests
- Add a licensed MP3 as `assets/audio/wedding-music.mp3` (not included).
- Configure a real RSVP backend; the form intentionally does not submit yet.
- Verify both Google Maps destinations on a phone.
- Check Armenian wording and all event details with the couple.

Do not publish private guest lists or secret credentials to GitHub.
